# Taller Rube Goldberg — Unity

Máquina de Rube Goldberg con el motor de físicas de Unity (6000.6.5f1).

Abre `Assets/Scenes/RubeGoldberg.unity` y dale Play. El contador en pantalla (`HitCounter.cs`) suma cada par distinto de piezas que chocan.

Cadena (15 golpes): bola roja baja la rampa → 10 dominós (con puntos, estilo real) → bola verde cae del pilar y baja la segunda rampa → 4 dominós finales.
